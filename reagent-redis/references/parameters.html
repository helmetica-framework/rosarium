Parameters

The values you can set in spec.values of an instance.

Path Type Default Description

alerting.enabled

boolean

true

alerting.serviceOperator.emailAddresses

[]string

[]

backup

object

How this service is backed up. The backup controller reads these off the instance; the framework itself knows nothing about backups.

backup.bucketAccessClassName

string

""

backup.bucketClassName

string

""

The COSI classes the bucket is provisioned from. Empty takes the backup controller’s default, which is how a cluster keeps all its backups in one place.

backup.enabled

boolean

true

Whether the service is backed up at all.

backup.mode

enum: Schedule, BucketOnly

Schedule

Who takes the backups. Schedule - the backup controller provisions a bucket and drives k8up over the service’s volumes. BucketOnly - it provisions the bucket and stops there, for a service whose own operator writes backups to object storage (CloudNativePG, MariaDB).

backup.retention

object

How many backups survive a prune. All zero takes the backup controller’s default retention. Only used with mode Schedule.

backup.retention.keepDaily

integer

0

backup.retention.keepHourly

integer

0

backup.retention.keepLast

integer

0

backup.retention.keepMonthly

integer

0

backup.retention.keepWeekly

integer

0

backup.retention.keepYearly

integer

0

backup.schedule

object

When each job runs, as a cron expression or a k8up shortcut like @daily-random. Only used with mode Schedule. An empty backup gets a nightly time between 22:00 and 06:00, generated from the name of the instance so that it stays put across upgrades and no two instances start in the same minute. Empty prune and check take the backup controller’s default, which runs them weekly.

backup.schedule.backup

string

""

backup.schedule.check

string

""

backup.schedule.prune

string

""

credentials.prefix

string

""

Prefix of the Secret name holding the connection details. Defaults to the claim name. Custos appends a hash of the claim’s group and kind; the full name is in the CredentialConfig’s status.secretName.

debug

object

Debug holds methods to debug the Helmetica bundle.

debug.heartbeatAlert

boolean

false

heartbeatAlert adds an alert always evaluating to be firing.

maintenance

object

When this service’s maintenance runs. The adept reads these off the instance.

maintenance.suspend

boolean

false

Whether maintenance runs at all. A suspended instance keeps its schedule and does not fire it.

maintenance.window

string

""

Which MaintenanceWindow this instance starts in. Empty takes the operator’s default window.

network.allowAllNamespaces

boolean

false

Allow access from all namespaces.

network.allowedNamespaces

[]string

[]

A list of allowed namespaces. The namespace where the claim resides is always included implicitly.

network.expose

boolean

false

Make this service reachable from outside the cluster: the proxy with three replicas, otherwise the headless service. The address and port are reported in the REDIS_EXTERNAL_* credentials. Sentinel is not exposed.

service.config

map[string]string

redis.conf entries. maxmemory and min-replicas-to-write are computed from the plan and the replica count, and win over anything set here. Values are strings, so a number needs quoting.

service.plan

enum: standard-1, standard-2, standard-4, standard-8

standard-1

The size of the instance. The number is gibibytes of memory the pod may use, and cpu follows it at 250 millicores per gibibyte. Requests are set equal to the limits, so the pod is Guaranteed.

service.replicas

enum: 1, 3

1

How many replicas of Redis should be running. 1 is a single instance 3 is for a replication cluster with Sentinel

service.storage

string

10Gi

The size of the data volume. Unrelated to the plan: a dataset that fits in memory still needs room on disk for the append only file and the snapshots beside it. Must be a valid quantity, and a claim cannot decrease it.
Validation: max length 32; storage must be a valid quantity; storage cannot be decreased

service.version

enum: 7.2, 8.2, 8.x

8.2

Which Redis version runs. 8.x is the newest 8 release 7.2 is the 7.x LTS release 8.2 is the 8.x LTS release (default)
