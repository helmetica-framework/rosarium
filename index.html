Reagents

Building reagents

  • Azoth: Helm library containing all the helpers for reagent

  • Cupel: Show diffs between helm chart versions and revisions. Either live on a cluster or from OCI charts.

  • Ferment: This repository contains a starter chart which is used by helmetica’s transmuter.

  • Transmuter: Wraps an upstream chart (prima materia) into a service chart (reagent).

Operators

  • Adept: Actions/operations runner for helmetica

  • Aludel cloudscale: aludel-cloudscale is a COSI driver for cloudscale.ch object storage

  • Ampulla: Kubernetes controller that turns backup intent on a Helmetica instance into a COSI bucket and a k8up schedule.

  • Chrysopoeia: A controller allowing self-service management of Helm charts in a GitOps way.

  • Custos: Custos handles credentials and secret management for services. It provides the access credential for the services to the end-user.

  • Libra: Libra handles collection of relevant data for billing. It only collects the data, passing it to an ERP is another tool’s job.

  • Sigillum: Controller to provide a platform agnostic API for all networking topics

Platform

  • Alembic: Unified deployment manifests for Helmetica

  • Athanor: Devcontainer based dev environment for the Helmetica Framework
