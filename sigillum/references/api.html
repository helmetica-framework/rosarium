API reference

ExposureClass

sigillum.helmetica.io/v1, cluster

ExposureClass describes how one protocol reaches the outside world.

An exposure that names no class falls back to the class named after its protocol, lowercased: TCP looks for "tcp", HTTPS for "https". There is no default flag, so two classes can never both claim a protocol.

Spec

Path Type Default Description

spec.domain

string

spec.gatewaySelector

object

GatewaySelector finds the gateway pods that must be allowed through the NetworkPolicy.

spec.gatewaySelector.namespaceSelector

object

A label selector is a label query over a set of resources. The result of matchLabels and matchExpressions are ANDed. An empty label selector matches all objects. A null label selector matches no objects.

spec.gatewaySelector.namespaceSelector.matchExpressions

[]object

matchExpressions is a list of label selector requirements. The requirements are ANDed.

spec.gatewaySelector.namespaceSelector.matchExpressions[].key (required)

string

key is the label key that the selector applies to.

spec.gatewaySelector.namespaceSelector.matchExpressions[].operator (required)

string

operator represents a key’s relationship to a set of values. Valid operators are In, NotIn, Exists and DoesNotExist.

spec.gatewaySelector.namespaceSelector.matchExpressions[].values

[]string

values is an array of string values. If the operator is In or NotIn, the values array must be non-empty. If the operator is Exists or DoesNotExist, the values array must be empty. This array is replaced during a strategic merge patch.

spec.gatewaySelector.namespaceSelector.matchLabels

map[string]string

matchLabels is a map of \{key,value} pairs. A single \{key,value} in the matchLabels map is equivalent to an element of matchExpressions, whose key field is "key", the operator is "In", and the values array contains only "value". The requirements are ANDed.

NetworkConfig

sigillum.helmetica.io/v1, namespaced

NetworkConfig is sigillum’s placeholder resource.

Spec

Path Type Default Description

spec.allowAllNamespaces

boolean

AllowAllNamespaces allows access from every namespace in the cluster, effectively disabling the NetworkPolicy. It overrides AllowedNamespaces and the claim namespace. Traffic from outside the cluster stays blocked.

spec.allowedNamespaces

[]string

AllowedNamespaces names the namespaces that may reach this one, on top of the claim namespace the network config’s own namespace is annotated with. Ignored when AllowAllNamespaces is true.

spec.expose

[]object

Expose asks for ways into this namespace from outside the cluster.
listType=map makes the API server reject duplicate names and makes server-side apply merge per entry rather than replacing the whole list.

spec.expose[].backend (required)

object

Backend names the in-namespace service an exposure points at.

spec.expose[].backend.port (required)

integer

Validation: minimum 1; maximum 65535

spec.expose[].backend.service (required)

string

Validation: min length 1; max length 63; pattern ^[a-z0-9]([-a-z0-9]*[a-z0-9])?$

spec.expose[].exposureClass

string

Empty means the class named after this exposure’s protocol, lowercased.

spec.expose[].name (required)

string

Name identifies the exposure within this NetworkConfig. It becomes the listener and route name, so it has to be a DNS label.
Validation: min length 1; max length 63; pattern ^[a-z0-9]([-a-z0-9]*[a-z0-9])?$

spec.expose[].protocol (required)

enum: HTTP, HTTPS, TCP

Protocol is what an exposure carries.

spec.expose[].subdomain

string

Empty means no subdomain label. HTTP and HTTPS only.
