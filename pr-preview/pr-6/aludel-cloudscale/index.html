Aludel cloudscale

An aludel is the sealed vessel an alchemist sublimes into — a container you put things in and close.

aludel-cloudscale is a COSI driver for cloudscale.ch object storage. It lets a Kubernetes workload ask for an S3 bucket with a BucketClaim and receive credentials in a Secret, without anybody touching the cloudscale.ch control panel.

It implements COSI v1alpha2, pinned to upstream commit 274540c (2026-10-19). See Status and Upgrading COSI.
